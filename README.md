# Vishal Kashyap — SAP S/4HANA Developer Portfolio

Static GitHub Pages-ready portfolio.

## Files
- `index.html` — website
- `style.css` — responsive visual design
- `script.js` — navigation, scroll progress and reveal animations
- `assets/Vishal-Kashyap-Resume.pdf` — downloadable resume

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/ (root)`.
5. Save and open the generated GitHub Pages URL.

No build step or framework is required.
